# Contributors

Start with [implementation architecture](architecture.md) to find the owner of a behavior. Use [testing](testing.md) for setup, local gates, and CI. [Documentation development](documentation.md) explains how to build and verify this handbook. [Releasing](releases.md) covers version selection and publication.

Keep private repositories, organization rules, generated company reports, research, and backups outside the public project. Examples should use fictional names and synthetic inputs. Preserve existing changes when working in a checkout.
