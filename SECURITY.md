# Security policy

Report vulnerabilities through [GitHub's private reporting form](https://github.com/beardedeagle/tech-radar/security/advisories/new). Please don't put vulnerability details or credentials in a public issue.

Include the output of `tech-radar version`, your operating system, steps to reproduce, and the impact. A small synthetic repository or input file helps. Remove private code, tokens and customer data before sending an example. If possible, check whether the issue also occurs on `main`.

I'll use the private advisory to discuss the report, a fix and disclosure. Please keep the details private until we've agreed on disclosure.

The [accepted limitations](https://beardedeagle.github.io/tech-radar/docs/reference/accepted-limitations/) describe known boundaries and their impact.

For bugs without a security impact, use the [bug report form](https://github.com/beardedeagle/tech-radar/issues/new?template=bug_report.yml).
